# ELIXIR OVERLAY — Android

Это исправленный исходный проект Android-приложения с плавающей панелью поверх других приложений.

## Что уже работает
- Нормальный экран приложения вместо пустых полос.
- Запрос системного разрешения «Показывать поверх других приложений».
- Плавающая панель, которую можно перетаскивать.
- Кнопка сворачивания в небольшой значок и кнопка закрытия.
- Демонстрационные строки для будущего распознавания карт.

## Важно
Автоматическое распознавание карт и эликсира **пока не реализовано**. Для него потребуется отдельный этап: захват экрана через Android MediaProjection с явным согласием пользователя, затем распознавание изображений/текста. Этот проект не читает экран скрытно и не управляет игрой автоматически.

## Как собрать APK через GitHub на телефоне
1. Создай репозиторий на GitHub.
2. Загрузи туда все файлы проекта, сохраняя структуру папок.
3. Открой вкладку **Actions** и включи GitHub Actions, если GitHub попросит.
4. Добавь workflow из `.github/workflows/build-apk.yml` (он уже включён в архив).
5. Запусти workflow **Build Android APK**.
6. Открой завершённый запуск и скачай артефакт `elixir-overlay-debug-apk`.
7. Распакуй ZIP и установи `app-debug.apk`. Android может попросить разрешить установку из браузера/файлового менеджера.

## Сборка на компьютере
Открой папку в Android Studio, дождись синхронизации Gradle и выбери **Build > Build APK(s)**.
